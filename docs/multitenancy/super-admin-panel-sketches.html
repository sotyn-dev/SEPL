Super-admin orchestration panel

Low-fidelity screens for the platform control room described in the tenant-model ideation doc. Audience: SEPL platform operators only — not tenant end-users.

Pair with: tenant-model-ideation.html · engineering notes: PHASE4-tenant-model.md
These are sketches for discussion, not product UI. Dashed frames mark “not implemented.” Product vision (Aug 2026): {slug}-erp.sotyn.com (wildcard DNS + auto SSL). All orgs Docker from day 1 — secured bind-mounts existing /root/erp/data/* (no move); new orgs use /var/lib/sotyn/tenants/{slug}/data. Platform at platform.sotyn.com drives a worker agent (local day‑1; remote on later VPSes). This panel onboards/monitors containers and controls features. Pricing / billing screens stay stubbed as later.
