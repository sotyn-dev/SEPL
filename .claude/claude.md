# CLAUDE.md

This repository follows the engineering standards defined in:

**/docs/ERP_ENGINEERING_PRINCIPLES.md**

Read and follow that document before making architectural or implementation decisions.

## Working Agreement

When implementing any feature:

1. Read the approved specification and implementation plan.
2. Follow the Engineering Principles document.
3. Raise architectural risks and open questions before writing code.
4. Do not invent business requirements or silently omit specification items.
5. Implement in small, reviewable phases.
6. Verify the implementation against the approved specification before considering the task complete.
7. Clearly identify any intentionally deferred work.

If the specification, implementation, or existing code disagree, stop and explain the conflict instead of making assumptions.

The approved specification is always the source of truth.
